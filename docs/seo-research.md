# ツールページ SEO 調査記録

調査日: 2026-09-07

## 位置づけ

公開前のため、Google Search Consoleによる表示回数や実検索クエリのデータはまだありません。本資料の検索語は、検索結果に現れる既存ツールの機能・表現と、各ツールで解決する作業をもとにした暫定案です。検索ボリュームの実測値を示すものではありません。

既存の「ブラウザ情報確認」「ダミー画像生成」は要件定義で指定された検索意図を引き継ぎます。新規ツールは次の観察をもとに、`app/data/toolSeo.ts`で対象ユーザー、検索意図、主要・副次検索語を管理します。

## 検索結果から確認した需要の形

| ツール           | 想定する作業                           | 観察した既存ページの特徴                                     | 暫定主要検索語           |
| ---------------- | -------------------------------------- | ------------------------------------------------------------ | ------------------------ |
| UUID生成         | テストデータ用のUUIDを複数作る         | v4、複数件、一括コピーを訴求するツールが存在                 | UUID v4 生成             |
| JWTデコーダー    | HeaderとPayload、有効期限を確認する    | JWT.ioなど、ブラウザでトークン内容を確認する専用ページが存在 | JWT デコード             |
| ハッシュ生成     | 文字列・ファイルのチェックサムを得る   | SHA-256とファイル入力、ローカル処理を訴求するツールが存在    | SHA256 ハッシュ 生成     |
| 文字数カウンター | 原稿や入力制限の文字数・容量を確認する | 文字数に加え、UTF-8バイト数、行数、単語数を示すツールが存在  | 文字数 バイト数 カウント |

JSON、Base64、URL、Unix時間は名称そのものが作業を表すため、「整形」「変換」「エンコード」「デコード」を主要な行動語として採用しています。タイトルや本文には、実装していない機能や測定できない効果を含めません。

## 実装上の確認項目

- title、H1、descriptionはページ固有とし、主要検索語と実際の機能を一致させる。
- canonical、パンくず、WebApplication構造化データ、サイトマップ掲載を生成HTMLで検査する。
- 関連ツールは作業の前後関係が説明できる場合だけ掲載する。
- 処理場所、入力データの扱い、制限事項、参考仕様をページ内に明記する。
- FAQはページ本文に表示する内容と構造化データを一致させる。

## 公開後の検証

公開後4〜8週間を初回の確認期間とし、Google Search Consoleでページ別に次を記録します。

1. 実際に表示された検索クエリ
2. 表示回数、クリック数、CTR、平均掲載順位
3. 想定検索意図とランディングページの一致
4. インデックス状況と構造化データのエラー

表示回数があるのにCTRが低い場合はtitleとdescriptionを、想定外のクエリで流入している場合は本文と副次検索語を見直します。機能追加は検索語だけを理由にせず、利用者の作業を完了できるかを確認して判断します。
